# Student Dating Bots — Professional V2.1

Учебная система из двух Telegram-ботов:

- основной бот знакомств;
- отдельный бот поддержки;
- единая SQLite-база;
- модерация, жалобы и бан;
- входящие симпатии с взаимной оценкой;
- фильтр «девушки / парни / все»;
- поиск пользователей для администратора;
- удаление собственной анкеты.

## Что исправлено в V2.1

1. Telegram username убран из обычной карточки анкеты.
2. В поиске сначала отправляются фотографии, затем текст анкеты и кнопки.
3. При взаимной симпатии username не показывается автоматически при обычном просмотре.
4. Добавлена очередь входящих симпатий: бот показывает, сколько людей тебя лайкнули, и предлагает посмотреть их анкеты.
5. В режиме входящих симпатий пользователь может поставить ответный лайк. Только после этого бот показывает username и сообщает о взаимной симпатии.
6. Кнопка «Не сейчас» возвращает в главное меню. При следующем входе в «Смотреть анкеты» бот снова напоминает о непросмотренных симпатиях.
7. Добавлена кнопка «Изменить поиск»: можно переключаться между девушками, парнями и всеми.
8. После жалобы профиль получает меньший приоритет в поиске. После 3 уникальных открытых жалоб профиль автоматически скрывается.
9. При бане пользователь получает уведомление со сроком блокировки. При снятии активного бана пользователь получает уведомление о разбане. Отдельное ручное скрытие анкеты пользователю не сообщается.
10. В боте поддержки нельзя создать новое обращение, пока предыдущее открыто.
11. `/find @username` корректно ищет username с символом `@` или без него. Поиск в админ-панели использует ту же логику.
12. Добавлена команда `/delete_profile` (также `/delete`) и кнопка `🗑 Удалить анкету`.
13. Политика конфиденциальности и этап согласия удалены из программной логики проекта.

## Установка

Python 3.11+.

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

Linux/macOS:

```bash
source .venv/bin/activate
```

```bash
pip install -r requirements.txt
```

Создайте `.env` на основе `.env`.

## Настройка `.env`

```env
BOT_TOKEN=токен_основного_бота
SUPPORT_BOT_TOKEN=токен_бота_поддержки
ADMIN_IDS=123456789,987654321
DB_PATH=bot.sqlite3
SUPPORT_BOT_USERNAME=your_support_bot
```

`ADMIN_IDS` — числовые Telegram ID администраторов через запятую.

## Запуск

В одном терминале:

```bash
python bot.py
```

Во втором:

```bash
python support_bot.py
```

Оба процесса должны использовать один и тот же `DB_PATH`.

## Взаимные симпатии

Если пользователь ищет девушек, бот может показать, например:

```text
💖 Ты понравился 5 девушкам, показать их?
```

Если пользователь — девушка:

```text
💖 Ты понравилась 5 парням, показать их?
```

Если выбран поиск всех:

```text
💖 Ты понравился 5 людям, показать их?
```

или:

```text
💖 Ты понравилась 5 людям, показать их?
```

Число берётся из базы и показывает количество непросмотренных входящих симпатий без ответного лайка.

## Удаление анкеты

Пользователь может использовать:

```text
/delete_profile
```

или:

```text
/delete
```

Также есть кнопка `🗑 Удалить анкету` в главном меню.

При подтверждении удаляются профиль и связанные с ним пользовательские данные, оценки и обращения поддержки.

## Тестирование

```bash
python smoke_test.py
```

Тест проверяет регистрацию данных в БД, входящие лайки, взаимную симпатию, жалобы, приоритет поиска, лимит обращений, бан/разбан и удаление пользователя.

## Важное ограничение Telegram

Несколько фотографий можно отправлять альбомом через `send_media_group`, но inline-кнопки нельзя прикрепить непосредственно к альбому. Поэтому при показе анкеты проект отправляет сначала альбом фотографий, а затем отдельное сообщение с текстом и кнопками.

## База данных

SQLite используется для учебной и небольшой нагрузки. Для крупного проекта рекомендуется PostgreSQL.
